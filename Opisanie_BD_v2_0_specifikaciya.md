# Спецификация утилиты — Описание базы данных

---

## Паспорт

- **Номер:** № 1 (сквозной по реестру утилит)
- **Название:** Описание базы данных
- **Версия:** 2.0
- **Категория:** для системного аналитика
- **Автор идеи:** Оксана Старкова
- **Реализация (вайб-код):** ИИ2-2 (создание), ИИ10 (безопасность и стандарт), ИИ10-2 (иконка, SQL-запрос, общий разбор таблиц)
- **Дата создания / доработок:** 06.06.2026 (создание) · 08.07.2026 (безопасность + стандарт, 1.0) · 12.08.2026 (доработка, 2.0)
- **Тип:** single-file HTML
- **Приватность:** полностью локально (в сеть ничего не уходит; localStorage — только настройки интерфейса)

## Назначение

Утилита формирует документацию структуры базы данных из выгрузки метаданных. На входе — файл со схемами, таблицами и полями (Excel или CSV, полученный SQL-запросом из системного каталога СУБД). На выходе — структура папок с Markdown-файлами: общая страница со списком таблиц по схемам и отдельный файл на каждую таблицу с её полями. Предназначена для наполнения базы знаний по БД.

## Вход и выход

- **Вход:** файл `.xlsx` / `.xls` / `.csv` с колонками «Схема», «Таблица», «Описание таблицы» и колонками характеристик поля («№ поля», «Поле», «Тип», «Описание поля», «Обязательное»). Каждая строка — одно поле.
- **Выход:** ZIP-архив со структурой папок по схемам; внутри — общая страница-указатель и по одному `.md`-файлу на таблицу. Имя архива — от имени загруженного файла. Настраивается набор выводимых колонок полей.

## Функциональность

- Блок «Откуда взять файл» на первом шаге: готовый SQL-запрос для PostgreSQL с кнопкой копирования и порядком действий (SELECT → CSV → при желании xlsx). Свёрнут по умолчанию.
- Загрузка Excel или CSV; встроенный офлайн-разбор (общий блок разбора таблиц, см. ниже).
- Группировка строк в структуру «схема → таблица → поля».
- Выбор колонок полей для вывода; добавление собственных пустых колонок (запоминаются локально).
- Генерация общей страницы (список таблиц по схемам) и отдельных файлов таблиц.
- Предпросмотр перед скачиванием.
- Скачивание результата ZIP-архивом со структурой папок.
- Кнопка «Очистить» — сброс файла, счётчиков, превью и выбора колонок; сохранённые настройки не трогаются.

## Технические детали

- Стек: HTML + CSS + JavaScript. Разбор `.xlsx` — собственный, на встроенном JSZip (xlsx = zip с XML). CSV — собственный парсер. Сборка ZIP результата — встроенный JSZip.
- **Общий блок разбора таблиц (версия блока 2, 12.08.2026)** — единый код для утилит № 1, № 3, № 4, № 7, побайтово одинаковый во всех четырёх. Умеет: определение разделителя CSV вне кавычек по стабильности числа колонок; склейку многострочных значений в кавычках; экранированные кавычки; снятие BOM; выбор первого листа `.xlsx` по порядку из книги, а не по имени файла; пустые строки листа; inline-строки. Правится в одном месте и раскладывается по всем четырём.
- Внешних библиотек и CDN нет: ранее использовавшийся SheetJS (0.18.5, с известными уязвимостями) удалён, JSZip встроен локально, Google Fonts убраны.
- Хранение данных: localStorage — только настройки интерфейса (дополнительные пустые колонки, выбор колонок общего списка). Данные таблиц не хранятся и не покидают браузер.
- Обращения в сеть: нет. Шрифты системные.
- Браузеры: любые современные.
- Ограничения: ожидается описанный выше формат колонок выгрузки; SQL-запрос в утилите — для PostgreSQL (в Oracle / MS SQL не выполнится); очень большие выгрузки обрабатываются в памяти вкладки.

## Оформление

Соответствует «Стандарту оформления утилит»: кремово-терракотовая палитра, системные шрифты + серифный заголовок (Georgia/Iowan Old Style), номер «№ 01» в правом верхнем углу, двухстрочный футер с версией и ссылками, иконка-искра вшита в base64 (4 размера: 16/32/48/64), версия в имени файла через подчёркивание (`Opisanie_BD_v2_0.html`). Отклонений нет.

## История версий

> Накопительный раздел. Новая финальная версия добавляется сверху; прежние записи не переписываются. В историю попадают только финальные версии — правки промежуточных сборок свёрнуты в запись той версии, которой они завершились.

### Версия 2.0 (12.08.2026, ИИ10-2)

**Добавлено**

- Блок «Откуда взять файл» на первом шаге: свёрнутый `<details>` с SQL-запросом для PostgreSQL, кнопкой копирования и порядком действий (SELECT → CSV → при желании xlsx). Раньше запрос лежал только на странице блога, и скачавший утилиту не знал, откуда брать выгрузку.
- Кнопка «Очистить» — сброс файла, счётчиков, превью и выбора колонок; сохранённые настройки не трогаются.
- Иконка-искра, вшитая в base64 (4 размера: 16/32/48/64).

**Изменено**

- Собственный парсер выгрузки заменён на **общий блок разбора таблиц** — единый код для утилит № 1, № 3, № 4, № 7, побайтово одинаковый во всех четырёх. Закрывает пункт «переиспользовать парсер с утилитой № 3»: улучшения больше не теряются поодиночке.
- Имя архива формируется от имени загруженного файла вместо постоянного `database-docs.zip`.
- Документация: уточнено, что именно сохраняется между запусками. README и прежняя спецификация утверждали, что запоминается выбор колонок полей, — по коду это не так. Решение Оксаны от 12.08.2026: поправить текст, поведение не менять.

**Исправлено**

- **Выбор листа `.xlsx`.** Первый лист определялся сортировкой по имени файла (`sheet1`, `sheet10`, `sheet2`) — если лист с данными лежал не в `sheet1.xml`, разбирался не тот. Теперь порядок берётся из `xl/workbook.xml` через связи книги.
- **Скачивание архива.** Ссылка не добавлялась в документ, а адрес блоба освобождался сразу после клика — в Firefox и Safari так можно потерять скачивание больших архивов.
- **Дублирование обработчика.** На выпадающий список превью обработчик навешивался заново при каждой загрузке файла: после трёх файлов подряд превью перерисовывалось трижды на каждое переключение.
- **Шрифт кнопок.** В трёх местах CSS ссылался на `IBM Plex Sans`, подключавшийся через Google Fonts; шрифты из сети удалили при чистке безопасности в 1.0, а ссылки остались — кнопки рисовались безымянным `sans-serif`, отличным от остального текста.

**Технические примечания**

- Общий блок разбора таблиц (версия блока 2) отдаёт `tbl_detectDelim`, `tbl_parseCsv`, `tbl_parseXlsx`; совместимые имена `parseCsvArrays` / `parseXlsxArrays` сохранены, чтобы не менять вызовы в теле утилиты.
- Блок правится в одном месте и переносится копированием во все четыре утилиты.

### Версия 1.0 (08.07.2026, ИИ10)

Первая версия. Безопасность: удалён внешний SheetJS с CDN (0.18.5, с известными уязвимостями), удалены Google Fonts; разбор `.xlsx` переписан на встроенный офлайн-парсер (JSZip + XML); добавлена поддержка CSV; убраны любые обращения в сеть. Оформление приведено к стандарту.

*Исходная сборка 0.4 (06.06.2026, ИИ2-2): разбор выгрузки, выбор колонок, генерация структуры папок и файлов, скачивание архивом.*
