# Описание базы данных

## Краткое описание

Утилита превращает выгрузку структуры базы данных в аккуратную документацию для базы знаний. Загружаешь файл со схемами, таблицами и полями (Excel или CSV) — получаешь готовую структуру папок: общую страницу со списком таблиц по схемам, а внутри — отдельный .md-файл на каждую таблицу с её полями. Удобно, когда нужно быстро задокументировать базу и положить это в вики или Confluence. Работает прямо в браузере, ничего устанавливать не нужно.

## Как работает

- **Где работает:** любой современный браузер (Chrome, Edge, Firefox, Safari). Ничего не устанавливается.
- **Откуда взять файл:** прямо в утилите, на первом шаге, есть блок «Откуда взять файл» — там лежит готовый SQL-запрос для PostgreSQL и кнопка «Копировать запрос». Выполнить запрос → выгрузить результат в CSV → при желании открыть в Excel и сохранить как `.xlsx`, чтобы удобнее было фильтровать.
- **Что делать:** загрузи файл (`.xlsx`, `.xls` или `.csv`). Выбери, какие колонки полей показывать. Утилита соберёт документацию и предложит скачать её архивом со структурой папок по схемам. Кнопка «Очистить» убирает файл и возвращает всё в начало.
- **Нюансы:** ожидается выгрузка, где есть колонки «Схема», «Таблица», «Описание таблицы» и колонки полей (номер, имя, тип, описание, обязательность) — ровно то, что даёт запрос из блока «Откуда взять файл». Имя архива берётся от имени загруженного файла.

## Что сохраняется между запусками

На твоём компьютере, локально, запоминаются только настройки интерфейса: дополнительные пустые колонки, которые ты добавила сама, и выбор колонок для общего списка таблиц. Набор колонок полей каждый раз начинается с того, что даёт стандартный запрос. Сами данные таблиц не сохраняются никогда.

## Приватность

Данные хранятся только на вашем компьютере, в интернет ничего не уходит. Файл читается и обрабатывается прямо в браузере; внешних библиотек и шрифтов из сети утилита не подгружает (разбор Excel встроен внутрь).
