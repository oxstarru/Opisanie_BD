# Описание базы данных

## Краткое описание

Утилита превращает выгрузку структуры базы данных в аккуратную документацию для базы знаний. Загружаешь файл со схемами, таблицами и полями (Excel или CSV) — получаешь готовую структуру папок: общую страницу со списком таблиц по схемам, а внутри — отдельный .md-файл на каждую таблицу с её полями. Удобно, когда нужно быстро задокументировать базу и положить это в вики или Confluence. Работает прямо в браузере, ничего устанавливать не нужно.

## Как работает

- **Где работает:** любой современный браузер (Chrome, Edge, Firefox, Safari). Ничего не устанавливается.
- **Что делать:** загрузи файл с описанием таблиц (Excel `.xlsx`/`.xls` или `.csv`, полученный SQL-скриптом). Выбери, какие колонки полей показывать. Утилита соберёт документацию и предложит скачать её архивом со структурой папок по схемам.
- **Нюансы:** ожидается выгрузка, где есть колонки «Схема», «Таблица», «Описание таблицы» и колонки полей (номер, имя, тип, описание, обязательность). Свой выбор колонок утилита запоминает между запусками — это единственное, что сохраняется, и только на твоём компьютере.

## Приватность

Данные хранятся только на вашем компьютере, в интернет ничего не уходит. Файл читается и обрабатывается прямо в браузере; внешних библиотек и шрифтов из сети утилита не подгружает (разбор Excel встроен внутрь). Локально сохраняется лишь ваш выбор отображаемых колонок — это настройка интерфейса, не данные таблиц.
