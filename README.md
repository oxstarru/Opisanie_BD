# Opisanie_BD
Описание БД (базы данных). Утилита превращает выгрузку структуры базы данных в аккуратную документацию для базы знаний. Загружаешь файл со схемами, таблицами и полями (Excel или CSV) — получаешь готовую структуру папок: общую страницу со списком таблиц по схемам, а внутри — отдельный .md-файл на каждую таблицу с её полями.
